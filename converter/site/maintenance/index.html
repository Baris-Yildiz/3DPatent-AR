    Maintenance notes

    This page documents intentional design decisions that look like bugs or omissions but are not. Read this before making changes.

    gc.disable() is intentional

    # main.py
import gc
gc.disable()

    bpy (Blender as a Python module) leaks memory when Python's cyclic garbage collector runs during scene construction. Disabling the GC prevents mid-conversion crashes. The process exits via os._exit(0) immediately after conversion, so no cleanup is needed.

    os._exit(0) is intentional

    # main.py
os._exit(0)

    Calling sys.exit() or letting the script fall off the end causes Blender's internal cleanup code to run, which reliably segfaults. os._exit(0) terminates the process immediately, bypassing all Python and Blender teardown.

    DRACO compression settings

    DRACO settings are defined as class variables on BPYExportConverter:

    DRACO_COMPRESS_LEVEL = 6
DRACO_QUANTIZATION_SETTINGS = (16, 12, 20, 12)  # position, normal, texcoord, generic

    These apply to all output formats, including the intermediate GLB produced by the FreeCAD pipeline. If you change them, test across FBX, OBJ, STL, and CAD outputs — quantization artifacts (especially low texcoord bits) are easy to miss on simple models.

    ufbx coordinate system settings

    FBXConverter loads FBX files with explicit axis and unit normalization:

    ufbx.load_file(...,
    target_axes=ufbx.CoordinateAxes.right_handed_y_up(),
    target_unit_meters=1.0,
    handedness_conversion_axis=ufbx.MirrorAxis.X,
)

    Do not change target_axes or handedness_conversion_axis without testing across models exported from multiple DCC tools (Maya, 3ds Max, Blender, Fusion 360). Different exporters embed different up-axis and handedness metadata. The current settings were chosen to produce correct results across all tested exporters.

    FreeCAD install path is hardcoded

    CADConverter appends a hardcoded path to sys.path before importing FreeCAD:

    sys.path.append("/usr/local/lib")

    This matches the cmake -DCMAKE_INSTALL_PREFIX=/usr/local install prefix in the Dockerfile. If the Dockerfile install prefix changes, this path must be updated to match.

    Error messages are in Turkish

    ImportLogHandler and ExportLogHandler write user-facing error messages to import_errors.json and export_errors.json in Turkish. This is intentional — the end-user interface is Turkish. Do not translate them to English.

    faulthandler is enabled at startup

    faulthandler.enable()

    This prints a C-level stack trace to stderr if the process crashes (segfault, abort). The output goes to the Docker container log. It has no effect on normal exits.
